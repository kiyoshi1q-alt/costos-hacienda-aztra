# costos-hacienda-aztra
# Grupo #10

## Objetivo General
Determinar y analizar los costos de producción de los cultivos de Arroz, Banano y Cacao de la Hacienda AZTRA mediante un sistema desarrollado en Java que permita optimizar la gestión de lotes e insumos y facilitar la toma de decisiones.

## Objetivos Específicos
- Implementar clases para la gestión de lotes e insumos.
- Aplicar herencia y polimorfismo para los diferentes tipos de cultivo.
- Utilizar el Patrón Strategy para el cálculo flexible de costos.
- Generar el costo total por lote de producción.

## Aporte del Grupo
Desarrollo de un sistema escalable que centraliza el cálculo de costos agrícolas, permitiendo a la hacienda identificar qué cultivo genera mayor rentabilidad y proponiendo como mejora futura la implementación de reportes y almacenamiento de datos históricos.
